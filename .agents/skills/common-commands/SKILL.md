# Common Commands

- **Run Backend (Hot Reload):** `cd backend && air`
- **Run Backend (Standard):** `cd backend && go run main.go`
- **Run Client:** `cd client && go run main.go`
- **Lint:** `go vet ./...`
- **Test:** `go test ./...`
