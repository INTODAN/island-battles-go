Map builder

Build an Island Battles map and download it as a map file for a lobby or for POST /map/create.

Checking the map…

    Drag a castle to move it, or select it and use the arrow keys (Shift for whole units). Double-click an empty spot to add a castle. Delete removes the selected castle. The plane is centred on the origin, and y grows downwards, as in the replay.

    Map

    Default soldiers start in every castle that sets no starting soldiers of its own.

      Castles

      A castle's number is its castle ID in every game built from the map.
